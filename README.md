# Поиск автозапчастей Favorit Parts

React + Redux Toolkit, JavaScript (без TypeScript), Bootstrap 5, Vite. Два этапа: поиск производителей по артикулу → получение предложений и аналогов выбранного бренда.

## Запуск

Node.js >=22.12.

```sh
npm ci
cp .env.example .env
```

Указать в `.env` действительный ключ покупателя:

```dotenv
FAVORIT_API_KEY=ваш_ключ
```

```sh
npm run dev
```

Открыть http://localhost:5173. Деморежима нет: приложение работает только с реальным API. Ключ нужен для обоих этапов поиска.

## FSD

```text
src/
  app/                    точка входа, store, стили
  pages/parts-search/     страница
  features/parts-search/  сценарий поиска, Redux, загрузка и ошибки
  entities/part/          API детали, нормализация, таблица
  shared/                 HTTP-клиент, форматирование, общий UI
```

Зависимости направлены сверху вниз. Между слайсами используются публичные index.js. Лишние слои, маршрутизация и универсальные абстракции не добавлены.

## Работа с API

Документация: https://lk.favorit-parts.ru/static/wsprice.pdf.

- Первый GET: `key`, `number`. Из `goods` собирается список уникальных производителей.
- Второй GET: `key`, `number`, `brand`, `analogues=on`. Аналоги находятся в `goods[].analogues`.
- Одна строка таблицы — одно складское предложение. Цена берётся только из `warehouses[].price`, остаток — из `warehouses[].stock`. Устаревший `goods.price` не используется.
- Пустые структуры в goods игнорируются; отсутствие товара, нулевой остаток, ошибки API и сети обрабатываются отдельно. Неизвестная цена не заменяется нулём.
- Спецсимволы кодируются через URLSearchParams.
- Поиск начинается от двух символов с задержкой 400 мс. При изменении запроса предыдущие результаты сбрасываются, запросы отменяются; requestId защищает от устаревших ответов.

Встроенный прокси Vite добавляет серверный FAVORIT_API_KEY и направляет `/api/parts` на документированный HTTP endpoint. Ключ не включается в клиентскую сборку. Дополнительного backend-приложения нет.

## Команды

```sh
npm run check    # ESLint, Prettier и сборка
npm run preview
```

`preview` доступен на http://localhost:4173 и использует тот же прокси. Статическая публикация папки dist требует отдельного прокси `/api/parts` на хостинге: Vite dev/preview не предназначены для production. После изменения ключа перезапустить Vite.

Реальные запросы к внешнему API не выполнялись. Для проверки интеграции нужно указать рабочий ключ. HTTP-адрес взят из документации.

## Стиль кода

- `npm run lint` — ESLint, включая правила React Hooks и неиспользуемые переменные.
- `npm run lint:fix` — автоматическое исправление замечаний ESLint.
- `npm run format` — форматирование исходников и конфигурации через Prettier.
- `npm run format:check` — проверка форматирования без изменения файлов.
- `npm run check` — все проверки одной командой.

Prettier: отступ 2 пробела, одинарные кавычки в JavaScript, точки с запятой, ширина строки 90 символов, переносы LF. `.editorconfig` задаёт базовые настройки редактора. `eslint-config-prettier` отключает конфликтующие правила форматирования.

ESLint также автоматически отделяет группы импортов и код после импортов, добавляет пустые строки перед `return`, условиями, циклами, функциями и экспортами, после многострочных блоков и групп объявлений переменных. Последовательные объявления переменных можно оставлять вместе. Правила: `import/order`, `import/newline-after-import`, `@stylistic/padding-line-between-statements`.
